# 공개용 요구사항 요약

이 문서는 도구가 무엇을 검증하고 무엇을 검증하지 않는지만 요약합니다. 운영 환경의 주소,
계정, 인프라 식별자는 포함하지 않습니다.

## 목적

격리 환경에서 동작하는 수집기와 그 뒤의 분석·전달 흐름을 세 영역에서 검증합니다.

1. HTML, JavaScript, 페이지 이동을 실제로 수집하는 기능
2. 가짜 스미싱 페이지가 요구하는 행동을 근거와 함께 분석하고 결과까지 전달하는 흐름
3. 허용 대상, 내부망 차단, 시간·크기·동시 실행 제한, 작업 간 분리를 포함한 격리 방어

## 구성

- 정적 합성 페이지는 개인 저장소의 Pages에서 제공합니다.
- HTTP 응답을 제어해야 하는 사례(리다이렉트, 지연, 큰 응답 등)는 별도 표본 서버가 제공합니다.
- 관리자 환경의 실행기가 사례를 실행하고 증거를 대조해 리포트를 만듭니다.
- 사례 원본은 JSON 명세 한 곳이며, 목록 페이지, 정적 페이지, 서버, 실행기가 이를 공유합니다.

## 도구 한도 (표본 기준)

- 표본 서버: 응답 지연 최대 20초, 스트림 수명 최대 20초, 압축 해제 최대 8 MiB,
  동시 처리 최대 4건, 대기열 없음(초과는 503).
- 실행기: 기본 동시 실행 1건. 동시성 시험은 수집기 상한 + 1건이며 8건을 넘지 않습니다.
  상한을 모르면 `blocked`입니다.
- 시간 기준: 첫 응답 5초, 격리 전체 작업 12초(+측정 여유 1초), 리다이렉트 5홉.
- 크기 경계(분석 쪽): HTML 131,072 bytes, 요소 2,000개, 텍스트 16,000자, 깊이 64,
  검사 결과 262,144 bytes.
- 컨테이너 비교 기준(기록용): 1.5 CPU, 메모리 1536 MiB, PIDs 256, shm 256 MiB,
  tmpfs 256 MiB. 도구는 실제 값을 기록할 뿐 운영 값을 바꾸지 않습니다.
- 공개 페이지는 합성 자료만 담습니다. 설정, 결과, 서버 수신 로그는 게시하지 않습니다.

## 미확인으로 보고하는 경우

다음은 통과가 아니라 `blocked` 또는 `not_run`입니다.

- 수집기가 스텁 응답을 주거나 필요한 증거 파일이 없을 때
- 정상 접속의 대조(양성 대조)가 실패해 차단 사례를 판단할 수 없을 때
- 접속 실패, CORS 오류, 타임아웃, 수신 기록 부재만 있을 때 (차단 통과의 근거가 되지 않음)
- 실행기만 시간 초과되어 원격 작업의 종료를 확인하지 못했을 때
- 한도 값을 알 수 없거나 표본으로 초과시킬 수 없을 때
- 지원하지 않는 영역(예: 닫힌 Shadow DOM 내부)은 "미확인 영역"으로 따로 보고

IP 허용은 정확한 사이트·경로 강제를 대신하지 않습니다. 이 도구는 장악된 프로세스가 같은
IP의 다른 사이트에 닿지 못한다고 주장하지 않습니다.

## 결과 기준

- 항목 상태: `passed`, `failed`, `not_run`, `blocked`.
- 사례에 변형이 여러 개면 변형별 결과를 보존하고, 하나라도 통과하지 못하면 사례 전체를
  통과로 표시하지 않습니다.
- 종합: 실패가 있으면 실패, 실패 없이 `blocked`/`not_run`이 있으면 미완료,
  필수 항목 전부 통과일 때만 통과.
- 종료 코드: 통과 0, 실패 1, 미완료 2.
- 도구 준비 완료(계약 시험 통과)와 환경 검증 완료(실제 배포·수집기·증거 확보)는 다릅니다.
  일부 그룹만 실행한 리포트는 전체 검증 완료가 아닙니다.
- 리포트는 URL 쿼리, 토큰, 쿠키, 인증 헤더를 제거하고 모든 값을 이스케이프하며,
  관측된 HTML을 실행 가능한 형태로 싣지 않습니다.
